# Лабораторная работа №5

Визуализация данных о погоде в Перми за 2021 год.

## Содержание

- `Lab05_solution.ipynb` — отчёт Jupyter Notebook с кодом и результатами.
- `lab05_solution.py` — самостоятельный Python-скрипт.
- `weather1.csv` — исходные данные.
- `Lab05.pdf` — задание лабораторной работы.
- `lab05_figures/` — сохранённые графики.

## Запуск

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Запуск скрипта:

```bash
python lab05_solution.py
```

Для открытия отчёта:

```bash
jupyter notebook Lab05_solution.ipynb
```

В работе используются `pandas`, `matplotlib` и `seaborn`. Выполнены все 9 пунктов задания: точечные диаграммы, временной график, среднемесячная температура, диаграмма облачности, гистограмма, boxplot и круговая диаграмма.
